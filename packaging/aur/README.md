# AUR packaging

This directory holds the [Arch User Repository](https://aur.archlinux.org/)
recipe for AlbusWall. It is kept in the upstream repository so a release and
its package metadata can be updated together, then copied into the AUR git
repository.

```text
packaging/
├── albuswall.desktop   # desktop entry (installed to /usr/share/applications)
└── aur/
    ├── PKGBUILD        # AUR recipe
    └── .SRCINFO        # generated by `makepkg --printsrcinfo`
```

The application icon lives where the app itself reads it from
(`src/albuswall/resources/icons/albuswall.svg`); `PKGBUILD` installs that same
file into `/usr/share/icons/hicolor/scalable/apps/albuswall.svg`, so the
desktop entry and the window icon can never drift apart.

## Package facts

| | |
|---|---|
| Package name | `albuswall` |
| Build type | `python-build` + `python-installer` (wheel), `arch=('any')` |
| Runtime deps | `python`, `python-psutil`, `python-pillow`, `python-apscheduler` (AUR), `pyside6` |
| Build deps | `python-build`, `python-hatchling`, `python-installer`, `python-wheel` |
| License | MIT, installed to `/usr/share/licenses/albuswall/LICENSE` |

## Releasing a new version

`PKGBUILD` pulls the GitHub tag archive:

```text
https://github.com/Zer0x70e8/albusWall/archive/refs/tags/v<pkgver>.tar.gz
```

That tarball only exists once the tag is pushed, so the checksum has to be
filled in afterwards:

```bash
# 1. bump the version in pyproject.toml / __about__.py, commit, tag, push
python scripts/aur_release.py --version 1.0.0   # pkgver is optional
```

The script downloads the tag archive, writes its `sha256` into `PKGBUILD`, and
regenerates `.SRCINFO`. Without network access, pass a local archive:

```bash
python scripts/aur_release.py --tarball /path/to/albusWall-1.0.0.tar.gz
```

Then publish:

```bash
git clone ssh://aur@aur.archlinux.org/albuswall.git
cp packaging/aur/PKGBUILD packaging/aur/.SRCINFO albuswall/
cd albuswall && git add -A && git commit -m "upgpkg: albuswall 1.0.0-1" && git push
```

## Verifying locally

```bash
cd packaging/aur
makepkg --printsrcinfo > .SRCINFO      # regenerate metadata only
makepkg -si                            # build and install
```

Notes:

- `sha256sums=('SKIP')` is only a placeholder for the not-yet-existing tag
  archive. Always run `scripts/aur_release.py` before publishing.
- `namcap albuswall-*.pkg.tar.zst` should stay clean; the recipe has no optdepends
  because every runtime dependency is a hard requirement of the built-in UI.
